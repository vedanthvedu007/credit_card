 
# Credit Card Fraud Detection Using Machine Learning

## Project Overview
This project detects fraudulent credit card transactions using machine learning techniques and investigates the effect of class imbalance handling.

## Algorithms Implemented
- Logistic Regression
- Decision Tree
- Random Forest
- Isolation Forest

## Class Imbalance Techniques
- Random Undersampling
- SMOTE (Synthetic Minority Over-sampling Technique)

## Dataset
The project uses the Credit Card Fraud Detection dataset from Kaggle.

Dataset link: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud

Download the `creditcard.csv` file and place it in your Google Drive folder named `Fraud_Detection_Project`.

## How to Run
1. Download the notebook from this repository.
2. Open it using Google Colab.
3. Download the dataset from the Kaggle link above.
4. Upload the dataset to your Google Drive folder.
5. Mount Google Drive and ensure the dataset path in the notebook is correct.
6. Run the notebook cells sequentially.

## Evaluation Metrics
- Precision
- Recall
- F1-Score
- ROC-AUC

## Development Environment
Python, Google Colab, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn and Imbalanced-learn.
